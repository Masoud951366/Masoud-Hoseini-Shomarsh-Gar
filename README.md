# شمارشگر شیشه (نسخه آزمایشی)

اپلیکیشن اندروید با پیش‌نمایش دوربین و ثبت عکس برای برآورد اولیه تعداد لبه‌های تکرارشونده شیشه‌ها.

## ساخت APK
با هر Push به شاخه `main` یا اجرای دستی GitHub Actions، فایل APK آزمایشی ساخته و به‌صورت Artifact بارگذاری می‌شود.

## وضعیت دقت
الگوریتم فعلی فقط یک تخمین تصویری مبتنی بر لبه‌های عمودی است و هنوز مدل آموزش‌دیده تشخیص شیشه نیست. برای رسیدن به شمارش قابل اتکا در بازه ۵۰ تا ۲۰۰ عدد، باید روی عکس‌های واقعی محیط کار آزمایش و الگوریتم/مدل تشخیص اختصاصی تنظیم شود.
